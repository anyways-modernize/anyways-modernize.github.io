Deploying Company Portal with WinGet

A cozy guide for deploying Microsoft Company Portal using WinGet and Intune.

Traditional packaging can feel like wandering through a dark cave with no lantern.

Why Use WinGet?

WinGet simplifies deployment and reduces maintenance overhead.

⚡ Tip: WinGet deployments work best on newer Windows builds.

Create the Install Script

winget install Microsoft.CompanyPortal --silent

Package as a Win32 App

IntuneWinAppUtil.exe

Final Thoughts

WinGet deployments feel much lighter once configured properly.
